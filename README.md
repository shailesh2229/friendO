# FriendO

**Discover friends with your interests** — art, photography, music, sports, gaming, technology, fitness, cooking and more.

**Live:** [friend-o.vercel.app](https://friend-o.vercel.app)

## What it does
- Sign up, log in and set up a profile with a photo
- Pick your interests and discover people who share them
- Home, Who we are, Discover and Contact pages

## Built with
Django · Python · HTML · CSS · Bootstrap 5

## Run it locally
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
